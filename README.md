# Assembly: Endgame

A "Guess the Word" game built with React, TypeScript, and Vite, developed during the "Learn TypeScript".

## Technologies Used
- **React 19**
- **TypeScript**
- **Vite** (for development and build)
- **ESLint** (linting)
- **react-confetti** (animations)
- **clsx** (CSS class management)

## How to Run the Project

1. **Install dependencies**

   ```bash
   npm install
   ```

2. **Start the development server**

   ```bash
   npm run dev
   ```
   The app will be available at `http://localhost:5173` (or as shown in the console).

3. **Build for production**

   ```bash
   npm run build
   ```
   The optimized files will be in the `dist/` folder.

4. **Preview the production build**

   ```bash
   npm run preview
   ```

5. **Lint the code**

   ```bash
   npm run lint
   ```

## Main Folder Structure

- `src/` — TypeScript/React source code
- `public/` — static files
- `dist/` — build output (git-ignored)

## Notes
- The `dist/` folder is ignored by the repository (`.gitignore`).
